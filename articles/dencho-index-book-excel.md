電子取引データの検索の要件は、ファイル名に日付・金額・取引先を入れる方法のほかに、Excel などで一覧表（索引簿）を作る方法でも満たせます。国税庁が Excel 形式のサンプルを公開しているので、それに沿って作れば難しくありません。ただ、入力の仕方を間違えると「範囲を指定した検索」ができなくなり、要件を満たさなくなります。この記事では、列の決め方と、やりがちな入力ミスをまとめます。

本文中の「問 ○○」は、国税庁「電子帳簿保存法一問一答【電子取引関係】」（令和 8 年 7 月）の番号です。

## 先に結論

**索引簿を手で入力するのが面倒なら、[電帳リネーム](https://dencho-rename.com/) の有料プランを使ってください。** 請求書・領収書の PDF を放り込むと、日付・金額・取引先を読み取ってファイル名を付け直し、この記事で説明する列の並びの索引簿 CSV をまとめて出します。Excel で開けばそのまま索引簿になります。自分で作る方は、このまま読み進めてください。列の並びだけ知りたい方は、[テンプレート](#テンプレート)の節へどうぞ。

## 索引簿とは何か

保存した請求書や領収書のデータを、1 件 1 行で並べた表です。表計算ソフトで「取引年月日その他の日付」「取引金額」「取引先」を入力し、その機能で範囲を指定した検索や、2 つ以上の項目を組み合わせた検索ができれば、検索の要件を満たすと国税庁は説明しています（問 50）。

表の行と実際のファイルを対応させておく必要があります。国税庁の例では、ファイル名を 1、2、3 … の通し番号にして、表の連番と合わせています。

ファイル名に 3 項目を入れる方法と比べると、名前を考える手間が無い代わりに、表への入力が必要です。件数が多く、金額や日付で絞り込むことが多いなら索引簿のほうが向いています。

## 列の決め方

国税庁のサンプルは「連番・日付・金額・取引先・備考」の 5 列です。私はこれに、あとで探しやすくするための列を足して次のようにしました。

| 列 | 入れるもの | 例 |
|---|---|---|
| 連番 | 1 から始まる通し番号。ファイル名を通し番号にするなら同じ番号にする | 1 |
| 取引年月日 | `2024-01-31` の形。Excel が日付として扱う | 2024-01-31 |
| 取引先 | 表記をそろえた取引先名 | 株式会社サンプル |
| 取引金額（税込） | 数字だけ。「円」などは入れない | 110000 |
| 書類種別 | 請求書、領収書、注文書など | 請求書 |
| 書類番号 | 請求書番号など。無ければ空欄 | INV-0012 |
| 保存ファイル名 | 行とファイルを対応させるための列 | 20240131_株式会社サンプル_110000.pdf |
| 元ファイル名 | 受け取ったときの名前。メールの添付から探すときに使う | invoice_final_v2.pdf |
| 備考 | 自由記入 | |

検索の要件に関わるのは「取引年月日」「取引金額」「取引先」の 3 列だけです。ほかは探しやすくするための列なので、要らなければ削っても構いません。

金額は、帳簿の経理方法（税抜経理・税込経理）に合わせるのが基本ですが、書類に書かれた金額を入れてもよいとされています（問 57）。税抜で入れるなら見出しを「取引金額（税抜）」にしておくと、あとで迷いません。

## Excel での検索のやり方

見出しの行を選んで［データ］→［フィルター］をオンにします。

- **日付の範囲:** 「取引年月日」の ▼ →［日付フィルター］→［指定の範囲内］
- **金額の範囲:** 「取引金額」の ▼ →［数値フィルター］→［指定の範囲内］
- **組み合わせ:** 「取引先」で絞ったあと、続けて「取引年月日」や「取引金額」で絞る。1 つの項目で検索した結果をさらに別の項目で絞り込む方法も、要件を満たすとされています（問 49）

Google スプレッドシートでも［データ］→［フィルタを作成］で同じことができます。

## 範囲検索が効かなくなる入力ミス

ここが一番の落とし穴です。見た目は表になっていても、Excel が日付や数値として扱っていないと、範囲の絞り込みができません。

1. **日付を文字で入れている。** 「2024.1.31」「1/31 請求分」のように入れると、文字列として扱われて日付フィルターが効きません。`2024-01-31` か `2024/1/31` の形で入れます。
2. **金額に文字を入れている。** 「110,000円」「11万円」は数値ではありません。数字だけを入れます。
3. **行とファイルの対応がずれる。** 並べ替えたあとに連番を振り直したり、ファイル名だけ変えたりすると、どの行がどのファイルか分からなくなります。連番は一度付けたら変えません。
4. **1 か月分をまとめた書類の日付と金額が合っていない。** 個々の取引で入れるか、発行日（または受領日）と合計金額で入れるか、どちらかに決めてそろえます（問 55）。
5. **索引簿だけ作って、改ざんを防ぐ措置をとっていない。** 検索の要件とは別に必要です（問 18）。事務処理規程のひな形は国税庁が公開しています。

セルの表示形式が「文字列」になっていないかは、［ホーム］→［数値］の表示形式で確認できます。すでに文字で入れてしまった列は、［データ］→［区切り位置］で一括で日付や数値に変換できます。

## 保存のときの注意

Excel 形式（.xlsx）で保存するのが無難です。CSV のまま保存するときは「CSV UTF-8」を選びます。ほかの CSV 形式だと、別のパソコンで開いたときに文字化けすることがあります。
